# Changelog

## [0.1.0] - 2026-05-09

Initial release.

- `SceneLoader` MonoBehaviour: additive load/unload of a configurable scene list with progress tracking.
- Custom inspector with "Refresh from Build Settings" button.
- `Window > Scene Loader` editor window: auto-discovers Build Settings scenes, per-scene Load/Unload/Ping, Load All / Unload All.
